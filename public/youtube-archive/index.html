YouTube Archive

Save authorized public YouTube videos to your own Google Drive, automatically or on request.

What the app does

The archiver checks configured creators once a day, downloads new authorized videos, and uploads them to a folder selected by the owner. Manual requests use the same process. The default quality is the best available video up to 480p, with audio.

Each completed video is recorded so repeat requests return the existing archive record. Failed work can be retried without marking an unfinished upload complete.

Why Google authorization is needed

The owner authorizes Google Drive access so the background job can inspect the destination, create subfolders, upload video files, and verify uploads. The requested Drive permission is broad, but the application uses the configured archive destination. An API key alone does not grant upload access.

Authorization takes place on Google's pages. This information site does not collect passwords, client secrets, or tokens. There is no public sign-up or upload endpoint.

Where your information goes

Video files are stored in the owner's Google Drive. Archive metadata is stored in a public GitHub repository. Files uploaded into a shared Drive folder inherit its sharing settings; a link-viewable destination is not private.

Read the privacy policy for details about permissions, storage, sharing, retention, and revoking access.
